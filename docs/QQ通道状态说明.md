# QQ 通道状态

工作台分开呈现会话服务同步和 QQ 通道状态。`GET /api/merchant/channels/qq` 仅供已登录商家读取，不返回 AppID、密钥、网关地址或平台响应正文。

QQ 进程每 5 秒把连接状态写入 `channel_runtime`。只有收到 WebSocket 的 READY／RESUMED 才记录连接成功；连接退出或异常后记录重连，正常停止时记录停止。进程被强制结束而来不及记录时，上报超过 20 秒即判定离线。没有上报记录则为未上报，不能从网页可访问推断机器人在线。

最近连接时间保留至下一次成功连接。数据库时间使用 UTC，API 返回明确时区，界面按设备本地时间显示。状态接口失败时显示状态未更新；状态请求独立轮询，不阻塞会话刷新。连接成功只表示通道连接，具体回复仍以消息投递结果为准。

新增表通过现有增量初始化建立，不修改既有会话。首次启用需要更新本机后端和 QQ 工作进程；旧工作进程不会主动上报。没有上报时不得直接显示在线。

验证包括商家认证、未知状态、心跳超时、异常未来时间、重连和重启保留最近连接时间、检查模式不写状态及启动失败记录停止。浏览器验证覆盖「服务已同步但 QQ 已离线」和重连恢复。
