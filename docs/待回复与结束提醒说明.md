# 待回复与结束前提醒

## 待回复

未读表示尚未查看，待回复表示当前人工接待仍需答复。查看记录、确认已读或接手均不清除待回复。有效商家回复覆盖本轮及客户最新补充后清除；客户再补充则重新显示，结束处理后清除。

网页回复以保存成功为准；QQ 回复须被平台接受才计为有效回复，队列等待、发送中、失败和结果不明均不提前清除。平台接受仍不表示客户已读。

判断由接口根据消息序号、当前交接及投递状态计算，不依赖前端本地标记。移动端提供待回复标签、独立筛选和工作台跟进入口，工作台在同类接待状态下优先展示待回复事项。

## 结束前提醒

打开结束确认框时先获取最新会话，核对成功前不允许确认。显示本轮待回复事项、尚在排队或发送中的 QQ 回复、未成功投递回复及结果不明确回复。提醒不会替使用者自动取消队列或补发，确认结束也不会取消已排队消息。

新界面提交结束时携带核对后的会话版本。若核对后又出现新消息或其他状态变化，后端返回 409，保持接待，要求重新核对后再次确认。已成功结束后的同一请求重试仍保持幂等。旧客户端不带版本的请求保留原兼容行为，不能据此声称旧版也有上述保护。
